MAROS — GitHub Pages
1) أنشئ مستودعًا جديدًا على GitHub.
2) ارفع index.html وstyle.css وscript.js إلى جذر المستودع.
3) افتح Settings > Pages.
4) اختر Deploy from a branch، ثم main و /(root)، واضغط Save.
5) انتظر نشر الموقع وافتح رابط Pages الذي يظهر.

مهم: GitHub Pages يستضيف واجهة الموقع الثابتة فقط، وليس ملفات PKG الكبيرة. زر التحميل غير مفعّل عمدًا. أضف رابطًا مباشرًا فقط لملف تملك حق توزيعه. تنزيل PKG لا يعني أن PS4 سيثبته مباشرة.
